===========================
Cortex.XSOAR 8 Release Notes
===========================

.. contents:: Topics

v1.0.0
======

Release Summary
---------------

Initial release of the Cortex XSOAR 8 SaaS Ansible collection.
Provides modules for managing API keys, credentials, integration instances,
jobs, lists, multi-tenant accounts, pre-process rules, server settings,
and syslog server integrations via the Cortex XSOAR 8 REST API.

New Modules
-----------

- cortex.xsoar8.api_key - Manage XSOAR 8 API keys.
- cortex.xsoar8.credential - Manage XSOAR 8 SaaS credential objects.
- cortex.xsoar8.integration - Manage XSOAR 8 SaaS integration instances.
- cortex.xsoar8.job - Manage XSOAR 8 scheduled jobs.
- cortex.xsoar8.list - Manage XSOAR 8 list objects.
- cortex.xsoar8.multi_tenant - Manage XSOAR 8 SaaS multi\-tenant child tenants.
- cortex.xsoar8.multi_tenant_sync_account - Sync content to XSOAR child tenants.
- cortex.xsoar8.pre_process_rule - Manage XSOAR 8 pre\-process rules.
- cortex.xsoar8.server_settings - Manage XSOAR 8 SaaS global server settings.
- cortex.xsoar8.syslog_server - Manage XSOAR 8 SaaS syslog server integrations.
